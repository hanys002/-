> 버전 0.1 (2026-11-09) · 기준: 대표 지시 조직안 + 진성 AI 사무실 벤치마킹(`docs/reference/`)


## 2. 운영 원칙

1. **단일 창구**: 대표는 김영 비서실장에게만 지시한다. 본부 배정은 김영이 한다.
2. **사람의 책임 영역**: 서명·날인, 계약 체결, 견적 확정, 외부 발송·제출·게시, 비용 지출은 대표만 결정한다.
   AI 산출물은 모두 **초안**이며, 기술사법에 따른 기술사의 책임은 대표 본인에게 있다.
3. **검토와 수정 분리**: 검토 지시에는 파일을 고치지 않는다. 수정은 별도 지시가 있을 때만 한다.
4. **근거 의무**: 법령·기준·수치는 출처(법령명·조문, 기준번호, 원자료 파일)를 함께 적는다. 근거가 없으면 "확인 필요"로 표기한다.
5. **보고 형식 고정**: 결론 → 꼭 고칠 것 → 고치면 좋을 것 → 손대지 않을 것 → 대표 확인 필요 사항.
6. **되돌릴 수 있게**: 수정 전 백업(`_백업/파일명_vN_YYMMDD`), 수정 후 변경 대조표와 렌더링 검수.
7. **교차검토**: 설계감리본부와 전자응용·계측제어본부는 기술 분야가 겹치는 성과품을 서로 검토한다.

## 3. 본부별 업무분장

### 3-1. 경영본부 · 김영 비서실장 (오케스트레이터 겸 행정지원)

| 기능 | 주요 업무 | 활용 도구·자산 |
|---|---|---|
| 비서실 | 지시 접수, 업무 분해·배정, 진척 관리, 대표 보고 | 업무 보드(`office/board/`) |
| 일정·연락 | 일정 등록, 메일 초안, 회신 관리 | Google Calendar, Gmail 커넥터 |
| 수주·영업 | 나라장터 입찰공고, 기술사 채용공고 수집·선별 | 기존 채용공고 데일리 파이프라인 |
| 법령 모니터 | 정보통신 관련 법령·고시 개정 추적 (전 본부 공용) | 기존 법령 주간 모니터 |
| 계약·견적 | 대가 산정, 견적서·계약서 초안 | 「엔지니어링사업 대가의 기준」, 「정보통신공사 설계·감리 대가기준」 |
| 문서행정 | 공문, 서식 점검, HWPX/PDF 변환, 문서 대장 | `pe-hwpx` 스킬 |
| 품질 게이트 | 대외 산출물 최종 형식 점검 (요건·빈칸·오탈자·개인정보) | 체크리스트 |
| 회계·총무 | 세금계산서, 비용 정리, 사무소 등록·신고 사항 관리 | (추후) |

### 3-2. 설계감리본부 · 지민 본부장

정보통신공사업법상 용역업자(기술사사무소)로서 수행하는 정보통신 설계·감리 업무.

| 기능 | 주요 업무 |
|---|---|
| 설계 | 구내통신·구내방송·CCTV·출입통제·홈네트워크·LAN·이동통신 중계설비 설계도서(설계설명서, 시방서, 내역서, 도면 검토) |
| 감리 | 감리계획, 착공·시공 검측 체크리스트, 감리일지, 공정·품질 점검, 감리 결과보고서 초안 |
| 인허가 지원 | 착공 전 설계도 확인, 사용 전 검사 대응 서류 |
| 기술기준 검토 | 방송통신설비의 기술기준에 관한 규정, 접지설비·구내통신설비·선로설비 및 통신공동구 등에 대한 기술기준, 지능형 홈네트워크 설비 설치 및 기술기준 적합성 |
| 설계 VE·검토 | 타사 설계도서 검토의견서 |

### 3-3. 전자응용·계측제어본부 · 해민 본부장

산업계측제어기술사·전자응용기술사 분야의 설계 검토, 기술자문, 감정.

| 기능 | 주요 업무 |
|---|---|

| 기능안전·보안 | SIS·SIL 검토(IEC 61508/61511), 제어시스템 보안(IEC 62443) 검토 |
| 전자응용 | 전원·회로·EMC/EMI 대책 검토, 전자장비 고장 원인 분석 |
| 기술자문·감정 | 기술검토의견서, 법원 감정 보조자료, 사고·하자 원인 분석 |
| 교차검토 | 설계감리본부 성과품 중 계측·제어·전원 분야 검토 |

## 4. 업무 흐름 (표준)

```
대표 지시 ─→ 김영: 접수·보드 등록 ─→ 본부 배정 ─→ 본부장: 검토/작성(초안)
                                                    │
                       ┌──── 기술 성과품이면 교차검토 ←┘
                       ↓
              김영: 품질 게이트(형식·요건) ─→ 대표 보고 ─→ 🔔 대표 승인
                                                              │
                                              외부 발송·제출·게시 (승인 후에만)
```

## 5. 결정권한 매트릭스 (RACI)

R = 실행, A = 최종 승인, C = 협의, I = 통보

| 업무 | 대표 | 김영 | 지민 | 해민 | 무근 |
|---|---|---|---|---|---|
| 업무 접수·배정 | I | A/R | I | I | I |
| 설계도서·감리보고서 초안 | A | C | R | C | — |
| 계측제어·전자 검토의견서 | A | C | C | R | — |
| 강의 교안·블로그 원고 | A | C | — | — | R |
| 견적·대가 산정 | A | R | C | C | C |
| 계약 체결 | A/R | C | I | I | I |
| 서명·날인 | A/R | — | — | — | — |
| 외부 메일 발송·제출 | A | R | — | — | — |
| 블로그·SNS 게시 | A | C | — | — | R |
| 법령 개정 반영 통보 | I | R | C | C | I |
