# 기술사 채용정보 → 카카오톡 알림

사람인 및 관련 협회(한국기술사회, 한국정보통신기술사회, 한국정보통신공사협회) 사이트에서
"기술사" 키워드로 채용정보를 검색해, 새로 올라온 공고만 카카오톡 "나에게 보내기"로
전송하는 파이썬 스크립트입니다.

## 폴더 구조

```
src/
  config.py          # .env 로딩
  kakao_auth.py       # 카카오 액세스/리프레시 토큰 최초 발급용 (1회만 실행)
  kakao_sender.py      # 카카오톡 '나에게 보내기' 전송 + 토큰 자동 갱신
  seen_store.py        # 이미 보낸 공고 기록 (중복 전송 방지)
  sites.py             # 크롤링 대상 협회 게시판 목록
  main.py               # 메인 실행 스크립트
  scrapers/
    saramin.py          # 사람인 키워드 검색
    generic_board.py     # 협회 게시판 범용 크롤러
data/seen.json           # 실행 시 자동 생성 (전송 이력)
```

## 1. 설치

```bash
pip install -r requirements.txt
cp .env.example .env
```

## 2. 카카오 개발자 설정 (최초 1회, 처음이라도 아래 순서대로만 하면 됩니다)

### 2-1. 앱 등록 및 REST API 키 발급
1. https://developers.kakao.com 접속 후 카카오 계정으로 로그인
2. 상단 **내 애플리케이션** → **애플리케이션 추가하기** → 앱 이름(예: "기술사 채용알림") 입력 후 저장
3. 생성된 앱 클릭 → 좌측 **앱 키** 메뉴에서 **REST API 키** 복사
4. `.env` 파일의 `KAKAO_REST_API_KEY=` 뒤에 붙여넣기

### 2-2. 카카오 로그인 활성화 & Redirect URI 등록
1. 좌측 메뉴 **카카오 로그인** → **활성화 설정** ON
2. 같은 화면의 **Redirect URI**에 아무 주소나 하나 등록 (예: `https://localhost.com`)
   - 실제로 그 주소가 열릴 필요는 없습니다. 인증 후 주소창에 뜨는 `code` 값만 복사하면 됩니다.
   - `.env`의 `KAKAO_REDIRECT_URI` 값도 여기 등록한 것과 **동일하게** 맞춰주세요.
3. 좌측 메뉴 **카카오 로그인 → 동의항목** 에서 **카카오톡 메시지 전송(talk_message)** 항목을 "필수 동의" 또는 "선택 동의"로 활성화
   - 목록에 없으면 **카카오톡 채널** 관련 설정이 아니라 **나에게 메시지 보내기** 권한인지 확인하세요. 앱을 처음 만들면 기본적으로 사용 가능하며, 별도의 사업자 심사는 필요 없습니다(개인 용도 "나에게 보내기" 기준).

### 2-3. 액세스 토큰 발급 (이 저장소의 도구 사용)
```bash
cd src
python kakao_auth.py url
```
1. 출력된 URL을 복사해 **브라우저**에 붙여넣고 접속
2. 카카오 로그인 → "카카오톡 메시지 전송" 동의 화면에서 **동의하고 계속하기**
3. 리다이렉트된 후 주소창의 URL을 확인 (예: `https://localhost.com/?code=AbCdEfG...`)
   - 페이지 자체는 열리지 않아도 됩니다(연결 오류가 떠도 정상). **주소창의 `code=` 뒤 값만** 복사하면 됩니다.
4. 복사한 코드로 토큰 교환:
```bash
python kakao_auth.py exchange AbCdEfG...
```
5. 완료되면 `.env`에 `KAKAO_ACCESS_TOKEN`, `KAKAO_REFRESH_TOKEN`이 자동 저장됩니다.
   (액세스 토큰이 만료돼도 `kakao_sender.py`가 refresh token으로 자동 갱신합니다. 다만 리프레시 토큰 자체도
   유효기간이 있으므로, 아주 오랫동안 실행하지 않으면 이 2-3단계를 다시 해야 할 수 있습니다.)

## 3. 검색 키워드 / 옵션 설정

`.env`의 `SEARCH_KEYWORDS`에 쉼표로 구분해 여러 키워드를 넣을 수 있습니다.
```
SEARCH_KEYWORDS=기술사,정보통신기술사
```
`SARAMIN_EXTRA_QUERY`에는 사람인 검색 URL에 추가로 붙일 파라미터(지역/직종 필터 등)를 넣을 수 있습니다.

## 4. 실행

```bash
cd src
python main.py
```

**처음 실행할 때 주의**: 그동안 각 사이트에 쌓여 있던 공고가 전부 "새 공고"로 인식되어
한꺼번에 카톡으로 전송될 수 있습니다. 이를 원치 않으면 최초 1회는 아래처럼 실행해
"확인 처리"만 해두고, 그 다음부터는 `python main.py`로 새로 올라오는 공고만 받으세요.
```bash
python main.py --seed
```

## 5. 주기적 실행 (cron)

리눅스/맥 기준, 1시간마다 실행하려면:
```bash
crontab -e
```
아래 줄 추가 (경로는 실제 프로젝트 경로로 수정):
```
0 * * * * cd /path/to/project/src && /usr/bin/python3 main.py >> /path/to/project/data/run.log 2>&1
```

## 6. 알아두어야 할 한계

- **사이트 구조 변경 대응**: `scrapers/generic_board.py`는 협회 게시판(한국기술사회, 한국정보통신기술사회,
  한국정보통신공사협회)의 실제 HTML을 이 실행 환경에서 직접 확인하지 못한 상태로(네트워크 정책상 접속 차단)
  작성되었습니다. 흔한 게시판 구조를 우선 시도하고, 실패 시 "그럴듯한 제목 링크"를 찾는 방식으로 이중
  안전장치를 뒀지만, 실제 사이트에서 공고가 하나도 안 잡히거나 이상한 항목이 섞여 나오면 브라우저
  개발자도구(F12)로 목록의 실제 태그/클래스를 확인한 뒤 `generic_board.py`의 `LIST_SELECTOR_CANDIDATES`
  맨 앞에 해당 사이트 전용 셀렉터를 추가해 주세요. 사람인은 상세페이지 링크에 항상 붙는 `rec_idx=` 파라미터를
  이용한 안정적인 백업 로직이 있어 상대적으로 안전합니다.
- `sites.py`에 등록된 협회 URL(특히 한국정보통신기술사회 `itpe.or.kr`)은 검색으로 찾아낸 주소이며,
  실제 접속 확인은 사용자 환경에서 한 번 해봐야 합니다.
- 각 사이트의 이용약관/robots.txt 범위 내에서 개인적인 용도로만 사용하고, 너무 잦은 주기(예: 분 단위)로
  돌리지 마세요.
- 카카오 "나에게 보내기"는 하루 호출 한도가 있습니다(개인 앱 기준 넉넉한 편이나, 신규 공고가 아주 많은 날은
  한도에 걸릴 수 있습니다).
